# ursim/programs

Mounted into the URSim container at `/ursim/programs`. PolyScope saves programs and installations here.

| File | Purpose |
|---|---|
| `default.installation` | Default PolyScope installation |
| `default.variables` | Default installation variables |
| `programs.UR5` | Default program data for the UR5 model |

See [`../README.md`](../README.md) to start URSim.
