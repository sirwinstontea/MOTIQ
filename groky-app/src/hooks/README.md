# hooks

| File | Purpose |
|---|---|
| `useVoice.ts` | Owns the voice session |
| `useSkills.ts` | Skill list, runs and stats |
| `useCamera.ts` | Camera selection and frames |
| `useDevices.tsx` | `DevicesProvider`: device status |
| `useNotify.tsx` | `NotifyProvider`: notification list |
| `useAlerts.ts` | Turns robot status changes and failed actions into notifications |
| `useHistory.ts` | Past requests |
| `useKeyboard.ts` | True while the on-screen keyboard is up. Never fires on web. |
