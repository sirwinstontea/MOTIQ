# components

| File | Purpose |
|---|---|
| `ui.tsx` | Primitives: `Button`, `IconButton`, `Segmented`, `Pill`, `Card`, `IconChip`, `Slider` |
| `Sidebar.tsx`, `BottomNav.tsx` | Desktop and mobile navigation |
| `Orb.tsx` | Assistant face, reacts to status and mic level |
| `ControlBar.tsx` | Session controls |
| `StopButton.tsx` | Stop. The only large danger fill in the app. |
| `Log.tsx` | Conversation log. Typing with no live session starts a text-only one. |
| `Activity.tsx` | What the agent is doing |
| `DeviceChips.tsx` | Robot status chips in the top bar |
| `Notifications.tsx` | Notification bell and list |
| `CameraPanel.tsx` | Camera view and controls, exposes `CameraHandle` |
| `TeachFromCamera.tsx` | Teach a skill by showing it |
| `SkillEditor.tsx` | Full skill editor |
| `SkillPreview.tsx` | Animated 2D preview. Conceptual only. |
| `Settings.tsx` | Voice and auth status, device URLs, robot-chooser hardware |
