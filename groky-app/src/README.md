# src

Application source. `App.tsx` at the app root wires these folders together.

| Path | Purpose |
|---|---|
| [`screens/`](screens) | Talk, Skills, Robots, Cameras, History |
| [`components/`](components) | Shared UI |
| [`hooks/`](hooks) | State and providers |
| [`voice/`](voice) | Grok Voice realtime session and audio |
| [`devices/`](devices) | Tool definitions and the bridge client |
| [`robot/`](robot) | UR5e kinematics, limits and live arm state |
| [`skills/`](skills) | Skill format, generation, validation and runner |
| [`preview/`](preview) | Skill animation timeline |
| [`lib/`](lib) | Approval, full access, cameras, chooser client, config |
| `theme.tsx` | Design tokens and theme provider. Dark is the primary theme. |
