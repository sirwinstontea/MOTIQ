# assets

App icons and images.

| File | Use |
|---|---|
| `icon.png` | App icon, set in `app.json` |
| `favicon.png` | Web favicon, set in `app.json` |
| `android-icon-foreground.png`, `android-icon-background.png`, `android-icon-monochrome.png` | Android adaptive icon layers, set in `app.json` |
| `splash-icon.png` | Splash image, not currently referenced by `app.json` |
