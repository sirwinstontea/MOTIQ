# vision

The Python package behind the vision stack. Run commands from `computer-vision/`.

| Package | Role |
|---|---|
| [`eyes/`](eyes) | Local perception: capture, tracking, masks, calibration, server |
| [`grok/`](grok) | Multimodal Grok tasks and voice tools |
| [`planner/`](planner) | Video to tokens, tokens to a validated skill, skill to execution |
